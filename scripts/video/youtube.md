# YouTube 업로드용 문구

- 파일: `out/synctx-demo.mp4` (4:29, 1920x1080 30fps, H.264 + AAC 48kHz 스테레오, 약 14MB)
- 자막: `out/synctx-demo.srt` (한국어, 50줄). 업로드 토큰으로는 자막을 못 올리므로 Studio에서 「자막 → 파일 업로드 → 타이밍 포함」으로 올린다.
- 공개 상태: 일부 공개(`--privacy unlisted`)
- 카테고리: 과학기술(28) / 아동용 아님
- 「변경되거나 합성된 콘텐츠」: 실존 인물·사건을 꾸민 장면이 없어 「아니요」로 둬도 된다. 설명에 AI 음성임을 적었다.
- 다시 녹화하면 챕터 시각이 바뀐다. `make.sh compose`가 출력하는 챕터로 아래 설명을 고친다.

## 제목

synctx 사용 데모: Git 마크다운 문서를 브라우저에서 읽고 회의·발표하기 (4분)

## 설명

Git 저장소의 마크다운 문서를 브라우저에서 바로 읽게 해 주는 synctx Viewer를 실제로 써 보며 소개합니다.
저장소와 문서 찾아가기, 검색, 문서 보기와 내려받기, 회의 모드, 발표 화면, 근거 미리보기, Marp 슬라이드 순서로 봅니다.

0:00 저장소·문서 찾아가기
0:37 문서 검색
1:06 문서 보기·내려받기
1:48 회의 모드
2:42 발표 화면
3:08 근거 미리보기·근거 모음
3:38 슬라이드(Marp)
4:05 마무리

- 화면: 로컬에서 띄운 Viewer와 가상의 「도서 대여 서비스」 시연 문서로 녹화했습니다. 문서 내용과 담당자 표기는 모두 예시입니다.
- 마우스 조작은 자동화 스크립트로 재생했습니다.
- 내레이션: AI 음성(Google Gemini TTS)
