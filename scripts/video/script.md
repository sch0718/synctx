# synctx 사용 데모 대본

- 화면: 로컬 Viewer(`scripts/local/run-viewer.sh`)를 헤드리스 Chrome 1280x720, 배율 1.5로 열고 CDP 스크린캐스트로 1920x1080에 담는다. 시연 문서는 `demo-docs/`의 가상 「도서 대여 서비스」.
- 목표 길이: 4분 안팎. 문장마다 음성을 먼저 만들고, 그 문장이 시작될 때 화면 동작을 시작한다.
- 한 문장 = 자막 한 줄. 녹화에 쓰는 문장은 `scenes.json`에 있고 이 표와 같게 둔다. 읽기만 다른 말(`synctx`→「싱크텍스」 등)은 `scenes.json`의 `speak`에 둔다.
- 장면 전환(메뉴 이동)은 첫 문장 **앞**에 말없이 한다. 그 장면 화면이 뜬 뒤에 첫 문장을 시작한다(`check_sync.py`로 확인).
- 테마 선택 목록은 펼치지 않고 값만 바꾼다.

## 1. 저장소·문서 찾아가기

| 화면 동작 | 말할 문장 |
|---|---|
| 저장소 목록. 커서가 제목 쪽으로 | 안녕하세요. Git 저장소에 있는 마크다운 문서를 브라우저에서 바로 읽게 해 주는 synctx를 소개해 드릴게요. |
| 「예시 문서」 카드 위로 | 첫 화면에는 등록된 저장소가 모여 있어요. |
| 카드에 머문다 | 오늘은 가상의 도서 대여 서비스 문서로 보여 드릴게요. |
| 카드를 눌러 저장소를 연다. 파일 트리를 훑는다 | 저장소를 열면 왼쪽에 폴더 트리가 나오고요. |
| 「설계/」 → 「시스템-구성.md」 | 설계 폴더에서 시스템 구성 문서를 열어 볼게요. |
| 표 → 흐름 그림 → 코드 블록으로 천천히 스크롤 | 표와 Mermaid 그림, 코드 블록이 Git에 적은 그대로 보기 좋게 그려져요. |
| 오른쪽 목차 「서비스 개요」를 누른다 | 오른쪽 목차를 누르면 그 절로 바로 옮겨 갑니다. |

## 2. 문서 검색

| 화면 동작 | 말할 문장 |
|---|---|
| (말 없이) ⌘K → 검색창이 열린 뒤 | 찾는 문서가 있으면 문서 화면에서 커맨드 K로 검색창을 열면 돼요. |
| 「대여」를 친다 | 대여라고 쳐 볼게요. |
| 「파일」 묶음 → 「본문」 묶음을 가리킨다 | 파일 이름이 맞는 문서가 먼저 나오고, 아래에는 본문에서 찾은 줄이 이어져요. |
| ↓ ↓ Enter → 문서가 열린다 | 화살표로 고르고 엔터를 누르면 그 문서가 바로 열립니다. |
| / → 「연체」 → 「전체 결과 보기」 | 결과를 모두 보고 싶으면 전체 결과 보기를 누르면 되고요. |
| 저장소 범위 「모든 저장소」 → 「검색」 | 검색 화면에서는 저장소 범위를 넓혀서 다시 찾을 수도 있어요. |

## 3. 문서 보기·내려받기

| 화면 동작 | 말할 문장 |
|---|---|
| (말 없이) 검색 결과에서 「시스템-구성.md」를 연 뒤. 상단 표시줄을 가리킨다 | 문서 화면 위쪽에서는 보는 방식을 바꿀 수 있어요. |
| 테마 → GitHub 어둡게 | 테마를 바꾸면 밤에 읽기 편한 어두운 화면이 되고요. |
| 테마 → Minimal | 조금 더 간결한 테마도 있어요. |
| 「내려받기」를 펼친다 | 내려받기에서는 원본 마크다운과 HTML, PDF 중에 고를 수 있습니다. |
| 「HTML」을 눌러 받는다 | HTML 파일로 받아서 따로 보관할 수도 있어요. |
| Esc, 테마를 GitHub 밝게로 되돌림 → 브랜치 draft → 같은 문서 | 브랜치를 바꾸면 아직 검토 중인 변경안도 볼 수 있어요. |
| 바뀐 「서비스 개요」 문장을 가리킨다 | 이 브랜치에는 대여 기간과 권수를 늘리자는 안이 올라와 있네요. |
| ? → 단축키 안내 → Esc | 물음표 키를 누르면 단축키 안내가 나와요. |

## 4. 회의 모드

| 화면 동작 | 말할 문장 |
|---|---|
| (말 없이) 브랜치 main → 「회의/」 → 「2026-11-주간-회의.md」 | 회의 문서는 맨 위에 회의 시간과 진행 상태가 카드로 보여요. |
| 「회의 모드로 열기」 | 회의 모드로 들어가면 문서를 보면서 바로 메모를 남길 수 있어요. |
| 「회의 모드 안내」를 읽듯 멈춘 뒤 「닫기」 | 회의 모드에 들어오면 사용법 안내가 먼저 나오고요. |
| 문단 옆 「이 부분에 메모 추가」 → 메모를 친다 | 문단 옆 더하기 단추로 그 부분에 메모를 달 수 있어요. |
| 문장을 드래그 → 「+ 선택 영역에 메모」 | 문장을 드래그해서 고르면 그 문장에 이어진 메모도 만들 수 있고요. |
| 메모 종류 → 결정, 내용을 친다 | 메모 종류를 결정으로 바꾸고, 정한 내용을 적어 둘게요. |
| 「+ 전체 메모」 → 액션, 할 일·담당자·기한 | 할 일은 액션으로 남기면 담당자와 기한도 같이 적을 수 있어요. |
| 「회의 정리」 탭 | 회의 정리 탭에는 결정과 액션만 모여서, |
| 「.md로 내보내기」 | 마크다운으로 내보내면 회의록으로 바로 쓸 수 있습니다. |

## 5. 발표 화면

| 화면 동작 | 말할 문장 |
|---|---|
| (말 없이) 「회의 모드 나가기」 → 「발표하기」 → 발표 화면이 뜬 뒤 | 같은 회의 문서를 발표 화면으로도 띄울 수 있어요. |
| 진행 막대·제목을 가리킨다 | 큰 제목마다 한 장씩 나뉘어서 안건 순서대로 넘어가요. |
| → → 스페이스 | 화살표나 스페이스로 넘기면 되고요. |
| 「메모 보기(N)」 → 메모 패널 | 메모 보기를 누르면 회의 모드에서 적은 메모가 옆에 나와서, 발표하면서 바로 확인할 수 있어요. |
| Esc → Esc → 문서 화면 | 이스케이프 키를 두 번 누르면 원래 문서로 돌아옵니다. |

## 6. 근거 미리보기·근거 모음

| 화면 동작 | 말할 문장 |
|---|---|
| (말 없이) 「대여 기간 검토」 안건으로 스크롤 | 안건 안에는 규칙 문서를 가리키는 근거 링크가 있어요. |
| 「대여 기간 조항」에 올린다 → 말풍선 | 링크에 마우스를 올리면 그 조항이 말풍선으로 미리 나와서, 문서를 옮겨 다니지 않아도 돼요. |
| Esc → 「연체 처리 조항」을 누른다 → 근거 모음 | 링크를 누르면 문서 끝의 근거 모음으로 내려가고요. |
| 근거 항목의 「인용한 곳」을 가리킨다 | 근거마다 어느 안건에서 인용했는지 함께 보여 줍니다. |
| 「연체 알림 개선」을 누른다 → 안건 | 인용한 곳을 누르면 그 안건으로 다시 돌아가요. |
| 근거 링크 → 모음 → 「원문 열기」 → 규칙 문서 | 원문 열기를 누르면 규칙 문서 전체를 볼 수 있습니다. |

## 7. 슬라이드(Marp)

| 화면 동작 | 말할 문장 |
|---|---|
| (말 없이) 파일 트리 「발표/」 → 「서비스-소개.md」 | 마지막으로 Marp 슬라이드예요. |
| 「슬라이드 미리보기」·「PDF 만들기」 단추를 가리킨다 | 문서 맨 위에 marp: true라고 적어 두면 이렇게 슬라이드 단추가 생겨요. |
| 「PDF 만들기」 → 진행 표시 → 내려받기 | PDF 만들기를 누르면 발표용 PDF를 만들어서 내려받고요. |
| 「슬라이드 미리보기」 → 새 탭(이후 이 탭을 녹화) | 미리보기를 누르면 새 탭에서 슬라이드가 열려요. |
| → → (대여 기준 표) | 마크다운 몇 줄이 이렇게 표가 들어간 슬라이드가 됩니다. |
