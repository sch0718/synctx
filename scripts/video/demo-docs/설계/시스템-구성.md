# 도서 대여 시스템 구성

책 검색부터 반납까지 한 화면에서 처리하는 서비스입니다.

## 서비스 개요

기본 대여 기간은 14일이며, 한 번에 3권까지 빌릴 수 있습니다.

읽고 싶은 책을 검색하고 대여 가능 여부를 확인합니다. 대여와 반납 이력은 운영 화면에서 조회합니다.

## 구성 요소

| 구성 요소 | 역할 | 확인할 항목 |
|---|---|---|
| 이용 화면 | 책 검색과 대여 신청 | 남은 수량 |
| 대여 처리 | 대여 기간과 한도 확인 | 연체 여부 |
| 도서 목록 | 책 정보와 재고 관리 | 대여 가능 수량 |
| 알림 처리 | 반납 예정 안내 | 알림 발송 결과 |

## 처리 흐름

```mermaid
flowchart LR
    사용자 --> 검색[책 검색]
    검색 --> 확인[대여 가능 확인]
    확인 --> 대여[대여 기록 저장]
    대여 --> 안내[반납 예정 안내]
    안내 --> 반납[반납 처리]
```

대여 요청을 받으면 재고와 연체 상태를 함께 확인합니다. 같은 책을 동시에 신청해도 재고보다 많이 빌려주지 않습니다.

## 대여 처리 예시

```python
def can_borrow(available, overdue):
    # 남은 책이 있고 연체가 없을 때 대여한다.
    return available > 0 and not overdue
```

반납 예정일은 대여 시각을 기준으로 계산합니다. 연체가 있으면 먼저 반납하도록 안내합니다.

## 설정 예시

```yaml
대여:
  기간_일: 14
  최대_권수: 3
알림:
  반납_전_일: 2
  재시도_횟수: 3
```

## 운영 확인

매일 대여 건수, 반납 건수, 연체 건수를 확인합니다. 알림이 실패하면 [장애 대응 절차](../운영/장애-대응.md)에 따라 처리합니다.

규칙을 바꾸기 전에는 [대여 규칙](대여-규칙.md)을 검토하고 회의에서 적용 시점을 정합니다.
