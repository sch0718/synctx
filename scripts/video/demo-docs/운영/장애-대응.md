# 도서 대여 장애 대응

## 대여 신청 실패

대여 기간과 남은 수량을 먼저 확인합니다. 연체로 제한된 신청인지 확인한 뒤 오류 기록을 조회합니다.

## 반납 알림 누락

반납 예정일과 알림 발송 기록을 대조합니다. 대여 기간이 연장되었다면 새 반납 예정일을 기준으로 확인합니다.

## 연체 상태 불일치

반납 기록이 있는데 연체로 표시되면 상태 갱신 작업을 확인합니다. 중복 실행 전에 기존 처리 결과를 조회합니다.

## 복구 후 확인

책 검색, 대여 신청, 반납 처리를 차례로 확인합니다. 원인과 복구 시각은 다음 주간 회의에서 공유합니다.
