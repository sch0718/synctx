# 도서 대여 서비스

책을 찾고, 빌리고, 함께 읽습니다.

시연용 예시 문서

---
# 이용 흐름

1. 읽고 싶은 책 검색
2. 남은 수량 확인
3. 대여 신청
4. 읽은 책 반납

---
# 대여 기준

| 항목 | 기준 |
|---|---|
| 대여 기간 | 14일 |
| 동시 대여 | 3권 |
| 연장 | 예약이 없으면 7일 |

---
# 운영 확인

- 반납 예정일 이틀 전 알림
- 연체 도서 반납 후 제한 해제
- 알림 발송 결과 확인

---
# 다음 단계

알림을 개선하고 이용자의 의견을 모읍니다.

함께 읽는 경험을 더 편하게 만듭니다.
