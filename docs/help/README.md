# synctx 도움말

<!-- 이 파일은 python3 scripts/build_motion.py로 생성합니다. 문구는 scripts/motion/help_pages.py에서 고칩니다. -->

Viewer의 메뉴마다 실제 화면 흐름을 움직이는 그림으로 보여 줍니다. 서비스 소개는 [README](../../README.md)에 있습니다.

| 메뉴 | 이렇게 써요 |
| --- | --- |
| [저장소·문서 찾아가기](browse.md) | 저장소 고르기 → 파일 트리에서 문서 고르기 → 본문 읽기 → 목차로 이동 |
| [문서 검색](search.md) | 검색 상자 열기 → 두 글자 이상 입력 → 결과 고르기 → 전체 결과 보기 |
| [문서 보기·내려받기](document.md) | 테마 바꾸기 → `내려받기` 열기 → 브랜치 바꾸기 → 단축키 보기 |
| [회의 모드](meeting.md) | `회의 모드로 열기` → 메모 달기 → 결정·액션 고르기 → `회의 정리`와 내보내기 |
| [발표 화면](present.md) | `발표하기` → 장 넘기기 → 메모 보기 → 발표 끝내기 |
| [근거 미리보기·근거 모음](evidence.md) | 근거 링크에 올리기 → 발췌 확인 → `근거 모음` 보기 → `원문 열기` |
| [슬라이드(Marp)](slides.md) | `슬라이드 미리보기` → `PDF 만들기` → `출판…` → 출판 확인 |

그림과 글은 `python3 scripts/build_motion.py`가 `scripts/motion/help_pages.py`로 만듭니다. 화면 문구가 바뀌면 그 파일을 고치고 다시 만드세요.
