`marp: true` 문서를 슬라이드로 보고 PDF로 받거나 팀 슬라이드 저장소에 출판합니다.

## 이렇게 써요

1. **`슬라이드 미리보기`** — 새 탭에서 슬라이드로 봅니다
2. **`PDF 만들기`** — `PDF 만드는 중…` 뒤 PDF를 내려받습니다
3. **`출판…`** — 출판할 저장소와 파일을 확인하고 `출판`을 누릅니다
4. **출판 확인** — `출판했습니다`의 `열기`로 Slides에서 봅니다

## 알아 두면 좋아요

- Front Matter에 `marp: true`가 있는 문서에만 단추가 보입니다. 테마는 `default`·`gaia`·`uncover`입니다.
- `출판…`은 운영자가 출판 저장소를 설정한 배포에만 있습니다. 권한이 없으면 `권한이 없습니다`가 뜹니다.
- PDF를 만들지 못하면 오류 알림의 `HTML로 받기`로 HTML 파일을 대신 받습니다.
